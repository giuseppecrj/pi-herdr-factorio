# Build skill source

The sandbox protocol is original to this repository. The applicable Feature or Bug fix playbook is read host-side from the pinned `pi-herdr-pstack` package in the asset bundle and inlined into the prompt. It is not copied from the controller's installed package or loaded through project skills. The bundle manifest binds the exact source bytes. Pstack remains a peer dependency. Publication and nested delegation steps are not authorized by the playbook.
