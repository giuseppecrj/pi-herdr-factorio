# research

> **Historical.** This folder records the design research from 2026-10-28. It explains why the factory looks the way it does. It does not describe current behavior. For that, read `docs/README.md`.

| Path | What it holds |
| --- | --- |
| `SYNTHESIS.md` | The original design synthesis. |
| `reports/` | The research and review reports behind it. |
| `PROVENANCE.md` | URLs, pinned SHAs and licenses of the upstream skill captures. `scripts/provenance.sh` regenerates it. |
| `upstream/` | Local-only upstream captures. Git ignores this folder because several upstreams carry no license. |

Do not edit these files to match later decisions. Record a new decision in `docs/decisions.tsv` instead.
